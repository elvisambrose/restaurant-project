# Restaurant Project
Author: Elvis

## Description
A site to make and view restaurant reservations. Users can submit a reservation form, and the data is saved using localStorage.

## Setup
1. Clone the repo
2. Open `index.html` in a browser

## Live Site
https://github.com/elvisambrose/restaurant-project.git

## Problem Statement
This project allows users to make and view restaurant reservations.

## Technologies
- HTML
- CSS
- JavaScript (localStorage)

## Known Issues
- Reservations are stored only locally, not on a server.

## Tests (Pseudo-coded)
- Test: Reservation form saves name, date, and time to localStorage
- Test: Saved reservation displays correctly on page load
- Test: Clear button removes reservation from localStorage
